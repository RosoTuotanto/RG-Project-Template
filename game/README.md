# game

Tämä on ryhmäsi pelin kansio. Tänne tulee kaikki, mitä peli tarvitsee toimiakseen.

Kansio on vielä tyhjä. Peli-ideoiden pitchauksen jälkeen ryhmä valitsee toteutettavan pelin ja sen pohjaksi tulevan Roso Games Templaten. Valittu template lisätään sitten tähän kansioon [RG-Game-Templates](https://github.com/RosoTuotanto/RG-Game-Templates)-repositoriosta.
